## 1. 실습 개요

사내 규정 문서 3종을 VectorStore에 적재하고, 사용자 질문과 의미적으로 유사한 근거 문서를 검색한 뒤
해당 근거만 사용하여 답변과 출처를 반환하는 RAG 기반 Q&A API를 구현하였다.

또한 문서에 존재하지 않는 질문에 대해서는 임의로 답을 생성하지 않고
`확인되지 않습니다.`를 반환하도록 구성하였다.

| 항목            | 내용                                                                        |
| --------------- | --------------------------------------------------------------------------- |
| 엔드포인트      | `POST /lab2/ingest` · `GET /lab2/retrieve` · `POST /lab2/ask`               |
| 구현 방식       | 직접 조립형 RAG — `similaritySearch` → 근거 포맷팅 → 프롬프트 → 구조화 응답 |
| 사용 스택       | JDK 21 · Spring Boot · Spring AI 2.0.0 · SimpleVectorStore                  |
| ChatClient 옵션 | temperature = 0.0 · maxTokens = 300                                         |
| 임베딩 모델     | `text-embedding-3-small`                                                    |
| Chat 모델       | `gpt-4o-mini`                                                               |
| 문서            | `return-policy.md` · `shipping-policy.md` · `membership.md`                 |

최종 기준선은 다음과 같이 설정하였다.

- chunk size: 400
- overlap: 0
- top-k: 4
- similarity threshold: 제한 없음
- temperature: 0.0
