# 멤버십 등급·포인트 정책

## 등급 기준 (직전 12개월 누적 구매액)
| 등급 | 기준 | 적립률 |
|---|---|---|
| 브론즈 | 신규 가입 | 0.5% |
| 실버 | 30만원 이상 | 1% |
| 골드 | 100만원 이상 | 3% |
| VIP | 300만원 이상 | 5% |

## 포인트 적립
- 결제 금액의 등급별 적립률만큼 포인트가 적립됩니다.
- 포인트는 구매 확정(수령 후 7일 경과) 시 지급됩니다.
- 반품·환불 시 적립된 포인트는 회수됩니다.

## 포인트 사용
- 1포인트 = 1원으로 사용할 수 있습니다.
- 최소 1,000포인트부터 사용 가능합니다.
- 포인트의 유효기간은 적립일로부터 1년입니다.

## 등급 산정 주기
- 등급은 매월 1일 기준으로 재산정됩니다.
- 등급 강등 시에도 다음 재산정일까지는 기존 등급이 유지됩니다.
