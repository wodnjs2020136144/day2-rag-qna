# 금융 고객정보 및 거래 보안 규정

문서명: Finance Customer Data Security Policy
버전: v1.0
담당부서: Information Security

## 개인 저장장치 사용

고객정보를 개인 USB 저장장치에 저장할 수 없다.

고객정보를 저장하거나 이동해야 하는 경우 회사에서 승인한 암호화 저장장치 또는 승인된 사내 시스템만 사용해야 한다.

예외적으로 외부 저장장치 사용이 필요한 경우 정보보안 담당자와 준법 담당자의 사전 승인을 받아야 한다.

## 거래정보 조회

거래 상태, 거래 금액, 승인 상태 등 실시간 거래 정보는 지정된 업무 시스템을 통해 조회해야 한다.

사용자는 자신에게 접근 권한이 부여된 거래 정보만 조회할 수 있다.

## 거래 오류 처리

거래 오류가 발견되면 임의로 거래 상태를 변경하지 않고 오류 처리 요청을 접수해야 한다.

오류 처리 요청은 담당자의 승인 이후 처리된다.
