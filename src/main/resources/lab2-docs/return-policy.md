# 반품·교환 정책

## 단순 변심 반품
- 단순 변심에 의한 반품은 상품 수령 후 **7일 이내**에만 가능합니다.
- 반품 배송비는 **고객이 부담**합니다.
- 상품 포장을 개봉했더라도 상품 자체를 사용하지 않았다면 반품이 가능합니다.
- 속옷, 식품 등 위생용품은 단순 변심 반품이 불가능합니다.

## 상품 불량·오배송
- 상품 불량이나 오배송으로 인한 반품·교환은 **배송비를 회사가 부담**합니다.
- 수령 후 30일 이내에 신고해 주세요.

## 교환 절차
1. 마이페이지 > 주문내역에서 교환 신청
2. 상품 회수 후 검수 (평균 2~3일 소요)
3. 검수 완료 후 새 상품 발송

## 환불
- 환불은 검수 완료 후 3영업일 이내에 원결제 수단으로 처리됩니다.
